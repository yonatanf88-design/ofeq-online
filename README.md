# אופק — למידה יומית בעברית

אתר למידה אישי בעברית עם ידע על מצוינות תפעולית, ניהול, כספים, תעשיית מזון, קריירה וחדשנות.

**אתר:** https://yonatanf88-design.github.io/ofeq-online/

## מה כבר עובד
- מאגר כרטיסיות מקצועיות בעברית עם שאלות, משימות, שמירה ומעקב
- פיד RSS של כותרות עם שם המפרסם, תאריך וקישור
- קפסולות AI מקצועיות **כאשר** `OPENAI_API_KEY` מוגדר, ורק כאשר ניתן למצוא תיאור מקור מספיק עשיר
- מיון קפסולות AI לפי תחומי העניין שסומנו בדפדפן

## הפעלת קפסולות AI — פעולה אחת בחשבון שלך

1. פתח [OpenAI API Keys](https://platform.openai.com/api-keys), הגדר חיוב לפי שימוש ותקציב, וצור מפתח API לפרויקט המיועד לאפליקציה. מנוי ChatGPT אינו כולל אוטומטית שימוש ב־API.
2. פתח את [Secrets של המאגר](https://github.com/yonatanf88-design/ofeq-online/settings/secrets/actions).
3. לחץ **New repository secret**. שם: `OPENAI_API_KEY`; ערך: המפתח שיצרת. **אין להכניס מפתחות לקוד, לאתר, או לשיחת ChatGPT.**
4. פתח את [Workflow](https://github.com/yonatanf88-design/ofeq-online/actions/workflows/publish.yml) → **Run workflow**.
5. בדוק בלוג ההרצה האם הופיע `Published N new AI learning cards`. אם לא, ההרצה לא מצאה מקורות מספקים או שנחסמה בקשת API. לא יתפרסמו סיכומים מומצאים.

## הבהרות מקור
- הקפסולות מסכמות **רק את תיאור ה־RSS שהמפרסם סיפק**; הן **לא** תמצית של המאמר המלא.
- היישום ומשימת היום הם הצעות AI היפותטיות, לא מידע שמופיע בהכרח במאמר.
- כל קפסולה כוללת שם המפרסם, כותרת המקור, תאריך פרסום וקישור.
- ניתן להפיק עד 3 קפסולות ביום מקבוצת מקורות קבועה, ולא מובטח שיהיו שלוש חדשות כל יום.
- המערכת מדלגת על מקורות שאין בהם תיאור מהימן מספק, ושומרת על התוכן הקודם במקרה של כשל.
- הכתבות והקפסולות שפורסמו במאגר הציבורי גלויות לכל. שם המשתמש, ההעדפות, והשמירות האישיות נשמרים בדפדפן בלבד, ללא סנכרון.
